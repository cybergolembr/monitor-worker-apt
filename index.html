0 Obter Credenciais

Antes de instalar, você precisa obter as credenciais de ativação no seu painel CyberGolem:

  • Acesse o dashboard no seu Cloud SaaS.
  • Vá em Infraestrutura > Workers.
  • Clique em Novo Worker ou selecione um existente.
  • Copie o Activated Token (API Key) e o Instance ID.
  • Se for monitorar logs, anote também o Log Stream ID.

1 Instalação Rápida (Recomendado)

O script de onboarding automatiza a configuração do repositório, solicita suas credenciais e configura o serviço systemd em um único passo.

curl -sSL https://cybergolembr.github.io/monitor-worker-apt/install.sh | sudo bash

2 Instalação Manual

Se preferir configurar manualmente, adicione a chave e o repositório:

curl -sS https://cybergolembr.github.io/monitor-worker-apt/public.key | sudo gpg --dearmor -o /usr/share/keyrings/monitor-worker-archive-keyring.gpg && \
echo "deb [signed-by=/usr/share/keyrings/monitor-worker-archive-keyring.gpg] https://cybergolembr.github.io/monitor-worker-apt/ stable main" | sudo tee /etc/apt/sources.list.d/monitor-worker.list

Depois instale o pacote:

sudo apt update && sudo apt install monitor-worker
